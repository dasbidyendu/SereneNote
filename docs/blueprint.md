# **App Name**: SereneNote

## Core Features:

- Landing Page: Informative landing page with standard sections like about, features, and call-to-action.
- Sign-in/Login: Secure authentication to allow users to access their personal journals.
- Mood Tracking Dashboard: Display a visual trend of the user's emotions over the past week, with options to navigate to different pages.
- Journal Entry: A dedicated page for users to create new journal entries.
- Private/Public Journals: Separate pages for viewing private and public journal entries, providing control over journal visibility.
- Daily Mood View: A calendar interface to review daily moods upon clicking a specific day.
- CBT Suggestions: Provide users with suggestions for alleviating stress or other mental conditions based on CBT principles; this tool will tailor its advice.
- Community Page: A page to view public journals of yours and others, and search for other users.

## Style Guidelines:

- Primary color: Light pink (#FFB6C1) to promote feelings of compassion and calm.
- Background color: Milky white (#FAF9F6), offering a clean, soothing, and unobtrusive background.
- Accent color: Dusty rose (#BC8F8F) for interactive elements, contrasting gently against the background and primary color.
- Body and headline font: 'Literata' serif for readability and vintage appeal.
- Use calming and friendly icons related to mood, feelings, and mental health practices. Use 3D icons or Lottie files to make the website more interactive.
- Employ a glass morphism effect with a milky appearance for UI elements, enhancing depth and visual appeal. Ensure legibility of all text against the glass morphism elements.
- Implement subtle animations for page transitions and interactions to create a smooth user experience. Use framer motion to add soft animations to the website
